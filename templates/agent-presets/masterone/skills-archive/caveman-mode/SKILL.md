# 🪓 Caveman High-Density Token Mode

Inspired by `JuliusBrussee/caveman`. Eliminates filler words, throat-clearing, and verbose preambles to achieve ~65% output token savings without sacrificing technical accuracy.

## CLI Usage
```bash
# Compress output or file into high-density tokens
bun ~/.dsh/scripts/caveman_compress.mjs <file_or_text>
```
