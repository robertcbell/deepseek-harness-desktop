# ✍️ Humanizer Writing Engine

Strips synthetic AI speech patterns, robotic filler, and throat-clearing openers.

## 🎯 Core Humanizer Principles
1. **No Robotic Preambles:** Never start with "Sure!", "Certainly!", "In today's fast-paced world...", or "Let's dive into...".
2. **High Information Density:** State the exact fact, command, or outcome directly.
3. **Natural Human Cadence:** Use active voice, clear sentence variety, and grounded engineering realism.
4. **Zero Cliché Words:** Ban words like "delve", "game-changer", "tapestry", "seamlessly", "testament", "unleash".

## 🛠️ CLI Cleaner
```bash
bun ~/.dsh/scripts/humanize_text.mjs <file_or_text>
```
