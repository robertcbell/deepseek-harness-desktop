## 📐 Clean Architecture & Spec Conventions

1. **Domain-Driven Boundaries**:
   - Separate pure domain logic from infrastructure, database adapters, and HTTP controllers.
2. **Spec-Driven Implementation**:
   - Write clear specifications and acceptance criteria before implementation.
3. **Automated Commit Discipline**:
   - Generate conventional, semantic commit messages summarizing exact intent and component boundaries.
