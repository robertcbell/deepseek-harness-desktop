# 🌐 Multica Multi-Agent Workspace

Manage multiple AI coding agents as collaborative teammates across persistent tasks.

## 🎯 Coordination Principles
1. **Agent Teammates:** Treat specialized subagents as persistent team members with clear ownership of tasks.
2. **Context Preservation:** Maintain project progress across sessions without losing intermediate decisions.
3. **Task Handoffs:** Structured handoffs from Planner $\rightarrow$ Worker $\rightarrow$ Reviewer $\rightarrow$ Tester.
4. **Skill Accumulation:** Every solved problem and pattern is captured into reusable skills for future sessions.
